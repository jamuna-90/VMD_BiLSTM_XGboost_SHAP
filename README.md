The following Python implementation presents a hybrid VMD–BiLSTM–XGBoost–SHAP framework for short-term wind speed forecasting at a 15-minute forecasting horizon. The methodology uses historical wind speed, meteorological, air-quality, wind-direction, and temporal features to predict the wind speed at the next 15-minute interval. The workflow consists of data preprocessing, future-target construction, VMD-based signal decomposition, causal temporal feature engineering, correlation-based feature selection, chronological train–test splitting, normalization analysis, XGBoost and BiLSTM model development, hybrid prediction, model evaluation, visualization, and SHAP-based model interpretation.

First, the Royapuram wind-speed dataset is loaded, converted into a chronological time-series format, and checked for invalid or missing observations. The forecasting target is generated by shifting the observed wind-speed series by one time step, corresponding to a 15-minute-ahead prediction. The wind-speed signal is subsequently decomposed using Variational Mode Decomposition (VMD) into multiple intrinsic modes, and the resulting VMD modes and residual component are incorporated as additional predictive features.

To capture temporal dependencies, lagged wind-speed variables, rolling statistical features, exponential moving averages, difference features, and cyclic time representations are generated. Wind direction is represented using sine and cosine transformations to preserve its circular nature. The complete feature set is then evaluated using Pearson correlation with the future wind-speed target, and features satisfying the specified correlation threshold are retained for model development.

A chronological 80:20 train–test split is used to preserve the temporal ordering of the observations. StandardScaler is applied to the input features for BiLSTM training, while MinMaxScaler is applied to the target variable. XGBoost is trained using the original feature values because tree-based models generally do not require feature normalization. The BiLSTM model uses a 96-step sliding window, representing 24 hours of historical information at 15-minute intervals, to learn temporal dependencies in the wind-speed sequence.

The XGBoost model captures nonlinear relationships among the engineered predictors, while the stacked Bidirectional LSTM architecture learns sequential patterns from the historical feature window. Their predictions are subsequently combined using a weighted hybrid strategy. The model performance is evaluated using MAE, RMSE, R², MAPE, and prediction accuracy within ±10% and ±20% error thresholds. Actual-versus-predicted and scatter plots are generated to visually assess forecasting performance.

Finally, SHAP (SHapley Additive exPlanations) is applied to the XGBoost component to interpret feature contributions and identify the relative influence of the selected predictors on wind-speed forecasting. The resulting SHAP beeswarm, bar, and waterfall plots provide global and local explanations of the model predictions. The complete implementation also saves the normalization summaries and forecasting figures for subsequent analysis and manuscript preparation.
